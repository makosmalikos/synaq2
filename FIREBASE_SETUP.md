# Настройка Firebase для входа и сохранения результатов

Проект: **synaq-88779** (конфиг уже вписан в frontend/src/firebase.js и landing/index.html).

## 1. Включить вход по почте/паролю
Firebase Console → Build → Authentication → Get started →
вкладка Sign-in method → включить **Email/Password** → Save.
(Ребёнок входит по логину+коду — под капотом это почта `логин@synaq.kids`,
поэтому отдельно ничего включать не нужно.)

## 2. Создать Firestore
Build → Firestore Database → Create database → регион eur3 → production mode.

## 3. Опубликовать правила
Firestore → вкладка Rules → вставить содержимое файла **firestore.rules** → Publish.
Правила: каждый видит только свои результаты; родитель видит результаты своего ребёнка;
waitlist можно только пополнять, читать нельзя.

## Как это работает
- Родитель регистрируется по почте+паролю и сразу задаёт ребёнку логин и код (код ≥ 6 символов).
- Ребёнок входит по логину+коду.
- Каждая решённая задача (тренировка) и каждый мок-тест сохраняются в Firestore под ребёнком.
- Родитель в своём разделе видит прогресс ребёнка по темам.

## Важно
- Код ребёнка — это пароль, минимум 6 символов (ограничение Firebase).
- Данные детей — персональные. Правила закрывают чужой доступ; не открывай read всем.
- Перед деплоем протестируй: зарегистрируй тестовую семью, войди ребёнком, реши задачу,
  проверь, что в Firestore появились коллекции results и progress.
