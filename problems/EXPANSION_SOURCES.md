# Пополнение банка до 5000 разных задач

Цель пользователя — **5000 разных по смыслу задач**, а не 5000 строк с переставленными числами. Текущий активный банк и грубую оценку разнообразия показывает `node scripts/bank-coverage.mjs`. Числовая нормализация лишь выявляет очевидные повторы; она не доказывает смысловую уникальность.

Существующие числовые варианты сохраняются для тренировки. В октябре 2026 года добавлены три партии, всего 90 авторских задач: 24 в `frontend/src/formatAlignedQuestions.js`, 36 в `frontend/src/formatAlignedQuestions2.js` и 30 в `frontend/src/formatAlignedQuestions3.js`, по 30 для НИШ, БИЛ и РФМШ. Это тренировочные задачи по структуре соответствующих разделов, а не реальные вопросы экзаменов. У каждой есть отдельное условие и объяснение; автоматическая числовая нормализация нашла 90 новых формулировок, но оценка смысловой уникальности остаётся редакторской задачей.

| Школа | Целевой объём разных задач | Приоритет пополнения |
|---|---:|---|
| НИШ | 2500 | математика, количественные характеристики, естествознание, языки |
| БИЛ | 1400 | математика, логика, грамотность чтения |
| РФМШ | 1100 | математика и логика с открытым целочисленным ответом |

Распределение — рабочая цель для наполнения, а не обещание, что все существующие задания уже отличаются по смыслу.

## Источники

1. **Локальный архив `problems/`**: продолжать сверку 1426 математических и 105 логических записей; проверенные переносить в `reviewedBilArchive.js`. Для 2259 визуальных записей нужны оригинальные PDF/сканы: в архиве отсутствуют условия и фигуры. Сначала искать дубли с полным условием, как у математических №5 и №47.
2. **[Официальные образцы НИШ](https://www.nis.edu.kz/ru/page/konkurstyq-irikteu-tapsyrmalarynyn-ulgileri)**: использовать для карты разделов, возраста, формы задания и уровня сложности. Не выдавать авторские задания SYNAQ за экзаменационные оригиналы.
3. **[Официальный формат РФМШ](https://admissions.fizmat.kz/ru/) и [пример вступительного задания](https://admissions.fizmat.kz/wp-content/uploads/sites/8/2022/04/7%D0%BA%D0%BB%D0%B0%D1%81%D1%811.pdf)**: ориентир для 7 класса, открытых ответов, математики и логики.
4. **[Архив задач и решений «Дарын» для 5–6 классов](https://daryn.kz/5-6-ro-rus/)**: ориентир для нестандартных математических сюжетов и сложности; подходит для составления собственных задач и ручной проверки идей.
5. **[Официальный сайт БИЛ](https://bil.edu.kz/?lang=ru)**: подтверждает разделы «математика–логика» и «грамотность чтения». Это ориентир по структуре; массового открытого банка с проверенными рисунками на сайте не найдено.
6. **[OpenAI GSM8K](https://github.com/openai/grade-school-math)**: около 7,5 тыс. англоязычных учебных математических сюжетов в тренировочном наборе, с решениями и числовыми ответами; [лицензия MIT](https://github.com/openai/grade-school-math/blob/master/LICENSE). Реальный кандидат для большой партии **разных** задач, но для SYNAQ нужны отбор по программе 5–6 классов, перевод/адаптация, проверка решения и сохранение уведомления о лицензии.
7. **[Казахский перевод GSM8K от kz-transformers](https://huggingface.co/datasets/kz-transformers/gsm8k-kk-translated)**: около 8,8 тыс. машинно переведённых записей, заявлена лицензия Apache-2.0; происхождение текста также требует сохранить уведомление об исходной MIT-лицензии. Это быстрее для подготовки казахской версии, но качество языка и математические условия нужно сверять с [английским оригиналом](https://github.com/openai/grade-school-math); перевод той же задачи **не считается** новой задачей. Есть также [казахская и русская тестовые части от ISSAI](https://huggingface.co/datasets/issai/GSM8k_Kazakh_Russian) по 1319 записей — это те же сюжеты GSM8K, а не дополнительные уникальные задачи.

## Правило публикации

Для каждой новой партии нужно вести отдельный реестр происхождения: исходный файл/URL, лицензию или разрешение, язык, школу, раздел и статус редакторской проверки. Текущая административная запись помечает источник только общим значением `admin`, поэтому точный URL пока нужно сохранять вне `bankTasks`; перед массовой загрузкой следует добавить отдельное поле происхождения. До публикации: проверить наличие всех данных; независимо пересчитать ответ; проверить единицы и формулировку; сравнить смысл с уже существующими задачами; воспроизвести рисунок как собственный SVG, если он нужен. Структурная валидация `npm run validate:bank` дополняет, но не заменяет эту содержательную проверку.

Через административный раздел банка можно импортировать UTF-8 CSV по 100 задач за пакет; импорт попадает в черновики, затем задачи проходят проверку и публикацию. Для больших проверенных серий можно добавить отдельный версионируемый модуль по образцу `reviewedBilArchive.js` и обновить каталог тем командой `node scripts/generate-topic-catalog.mjs --write`.
